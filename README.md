## ✨ Fonctionnalités

### 🔍 Capacités de Recherche

- **Recherche Rapide** : Recherche rapide de livres par mots-clés
- **Recherche Avancée** avec plusieurs filtres :
  - Titre
  - Auteur
  - Sujet / Catégorie

### 📄 Affichage des Résultats

- Présentation moderne sous forme de cartes avec :
  - Couvertures des livres
  - Titre et informations sur l'auteur
  - Année de publication
- **Pagination** : 100 livres par page
- Navigation fluide sans rechargement de page
- Gestion complète des états :
  - États de chargement
  - Gestion des résultats vides
  - Gestion des erreurs API

### 🎨 Interface Utilisateur

- Design moderne et épuré
- Mise en page entièrement responsive
- En-tête de recherche persistant
- Pied de page informatif
- Optimisé pour mobile, tablette et ordinateur

## 🛠️ Stack Technique

### Technologies Principales

- **React 18+** - Bibliothèque UI
- **TypeScript** - JavaScript typé
- **Vite** - Outil de build nouvelle génération
- **React Router** - Routage côté client

### Style & UI

- **Tailwind CSS** - Framework CSS utilitaire
- **Lucide React** - Bibliothèque d'icônes élégantes

### Tests

- **Cypress** - Framework de tests end-to-end

### API & Données

- **Open Library API** - Source de données des livres
- **Axios** - Client HTTP

### Outils de Développement

- **React Hook Form** - Gestion des formulaires
- **date-fns** - Bibliothèque utilitaire de dates
- **Autoprefixer** - Préfixage CSS automatique
- **ts-node** - Exécution TypeScript

## 📦 Installation

### Prérequis

- **Node.js** ≥ 18.0.0
- **npm** ou **yarn**

### Cloner le Dépôt

```bash
git clone https://github.com/{VOTRE_NOM_UTILISATEUR}/3WEBD.git
cd 3WEBD
```

### Installer les Dépendances

```bash
cd src/app
npm install
```

---

## 🚀 Utilisation

### Mode Développement

Démarrer le serveur de développement :

```bash
npm run dev
```

L'application sera disponible sur `http://localhost:5173`

## 🌐 Intégration API

Cette application utilise l'**API Open Library** pour récupérer les données des livres et l'**API Wikipedia** pour récupérer des données additionnelles.

### Fonctionnalités API Utilisées

- Recherche en texte intégral
- Filtrage par facettes
- Support de la pagination
- Récupération des images de couverture

**Documentation API** : [Open Library Docs](https://openlibrary.org/developers/api)
